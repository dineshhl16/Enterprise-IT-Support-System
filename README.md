# Enterprise IT Support & System Administration Lab

## Project Overview
This project demonstrates practical IT Support and System Administration concepts through a simulated enterprise IT environment. It covers Windows and Linux administration, user account management, network troubleshooting, server configuration, and basic automation.

## Objectives
- Understand enterprise IT infrastructure and system administration.
- Practice Windows and Linux troubleshooting.
- Manage users, groups, permissions, and access policies.
- Configure and troubleshoot basic network services.
- Develop technical troubleshooting and documentation skills.

## Technologies & Tools
- **Operating Systems:** Windows 10/11, Windows Server, Linux
- **Directory Services:** Active Directory
- **Network Services:** DNS, DHCP
- **Networking Tools:** Ping, IPConfig, Tracert, NSLookup
- **Automation:** PowerShell
- **Other Areas:** Group Policy, IT Ticketing, System Troubleshooting

## Project Modules

### 1. Windows Troubleshooting
- Windows operating system troubleshooting.
- Software installation and configuration.
- Basic system maintenance and issue resolution.

### 2. Linux Administration
- Basic Linux commands and file management.
- User and permission management.
- Process and service management.

### 3. Active Directory
- User and group management.
- Password resets and account administration.
- Access permissions and organizational units.

### 4. DNS and DHCP
- Understanding DNS name resolution.
- DHCP configuration and IP address allocation.
- Basic network connectivity troubleshooting.

### 5. Group Policy Management
- Understanding Group Policy Objects (GPOs).
- Applying policies to users and computers.
- Managing basic security and configuration settings.

### 6. Network Diagnostics
- Connectivity testing using Ping.
- Network configuration using IPConfig.
- Route analysis using Tracert.
- DNS troubleshooting using NSLookup.

### 7. PowerShell Automation
- Basic PowerShell commands.
- Automating routine administrative tasks.
- User and system information management.

### 8. IT Ticketing and Documentation
- Recording technical issues.
- Documenting troubleshooting steps and resolutions.
- Understanding incident prioritization and escalation.

## Learning Outcomes
- Improved understanding of IT support operations.
- Knowledge of Windows and Linux system administration.
- Familiarity with Active Directory and network services.
- Practical troubleshooting and problem-solving skills.
- Basic PowerShell automation experience.
- Understanding of IT incident management workflows.

## Disclaimer
This is a hands-on learning project based on a simulated enterprise IT environment. Configurations and activities are documented for educational and demonstration purposes.
